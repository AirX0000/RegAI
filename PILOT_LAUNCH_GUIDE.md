## 1. Быстрый запуск через Docker (Рекомендуемый)

Для запуска всех сервисов (Frontend, Backend, PostgreSQL, ChromaDB Vector Store) требуется только установленный **Docker & Docker Compose**.

```bash
# 1. Перейдите в корень проекта
cd regai

# 2. Запустите стек сервисов
docker compose -f ops/compose/docker-compose.dev.yml up --build
```

### Доступ к сервисам:
- **Веб-интерфейс (Frontend):** [http://localhost:5173](http://localhost:5173)
- **API документация (Swagger/OpenAPI):** [http://localhost:8000/docs](http://localhost:8000/docs)
- **Метрики Prometheus:** [http://localhost:8000/metrics](http://localhost:8000/metrics)

## 2. Локальный запуск без Docker

### Требования к окружению:
- **Node.js:** v18+ или v20+
- **Python:** 3.11 или 3.12
- **OCR зависимости (для распознавания сканов/PDF):**
  - *macOS:* `brew install tesseract poppler`
  - *Ubuntu/Debian:* `sudo apt-get install tesseract-ocr tesseract-ocr-rus poppler-utils`

### Шаг 1: Запуск Backend
```bash
cd regai/backend

# Создание и активация venv
python3 -m venv venv
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### Шаг 2: Запуск Frontend
```bash
cd regai/frontend

# Установка зависимостей
npm install

# Запуск Vite dev-сервера
npm run dev
```

## 4. Сценарии для тестирования функционала

### Сценарий 1: Трансформация финансовой отчетности (MCFO ↔ IFRS)
1. Авторизуйтесь как **Бухгалтер** (`test.accountant@techcorp.com` / `password`).
2. Перейдите в раздел **Трансформация (Transformation)** в верхнем меню.
3. Нажмите **"Новый баланс" (New Balance Sheet)**:
   - Введите статьи баланса вручную либо загрузите шаблон Excel (`balance_sheet_template.xlsx`).
   - Проверьте работу автоматической валидации баланса (*Активы = Обязательства + Собственный капитал*).
4. Перейдите на вкладку **Результаты (Results)**:
   - Оцените автоматическую реклассификацию статей из национального плана счетов в стандарты МСФО (IFRS).
   - При необходимости добавьте реклассификационную проводку во вкладке **Корректировки (Adjustments)**.
   - Скачайте отчет в формате Excel / JSON.

### Сценарий 2: Интеллектуальный анализ нормативного влияния (Impact Analysis)
1. Откройте раздел **Регуляции (Regulations)**.
2. Воспользуйтесь умным поиском (например, по запросу `IFRS 15`, `Налог на прибыль` или `GDPR`).
3. Откройте карточку выбранной регуляции и нажмите **"Анализ влияния на компанию" (Analyze Impact)**.
4. ИИ сформирует персональный скоринг влияния (от 1 до 10), резюме для руководства и пошаговый чек-лист действий.

### Сценарий 3: Умное извлечение данных из документов (Smart Document OCR)
1. Откройте раздел **Документы (Documents)** (`/documents`).
2. Загрузите PDF-файл или скан инвойса / договора.
3. Система автоматически распознает текст через OCR и извлечет ключевые сущности: номер документа, дату, контрагента, суммы, НДС и товарные позиции.

### Сценарий 4: Демонстрация двусторонней интеграции с 1С:Предприятие 8.3
1. **Настройка подключения:**
   - Перейдите в раздел **Настройки компании (Company Settings)** → блок **1C:Enterprise 8.3 OData Integration**.
   - Нажмите **"Connection Settings"**: укажите OData URL (например, `http://1c-server/base/odata/standard.odata/` или `mock`), выберите тип авторизации (Basic Auth / Bearer Token), логин и пароль.
   - Нажмите **"Test Connection"** — система выполнит ping сервиса метаданных и отобразит статус с реальным задержкой сети (Latency в мс). Сохраните настройки (учетные данные будут зашифрованы AES-256).
2. **Импорт ОСВ / Баланса (1С ➔ RegAI):**
   - Нажмите **"Open Sync Hub"** (или кнопку **"1C:Enterprise Sync"** в разделе Трансформация).
   - Выберите отчетный период (например, `2024 Full Year` или `Q4 2024`).
   - Нажмите **"Extract & Sync from 1C"** — система выполнит запрос к регистру `AccountingRegister_Хозрасчетный`, нормализует план счетов РСБУ (01, 10, 51, 60, 80 и т.д.) и автоматически создаст готовый баланс с проверкой равенства $Активы = Обязательства + Капитал$.
3. **Экспорт МСФО-корректировок (RegAI ➔ 1С — Pushback):**
   - Перейдите на вкладку **"RegAI ➔ 1С: Export IFRS Adjustments"**.
   - Укажите баланс и нажмите **"Push Adjustments to 1C"**.
   - Корректировки будут выгружены в 1С в виде сформированного документа `Document_ОперацияБух` с номером и GUID.
4. **Аудит синхронизации:**
   - В блоке **1C Integration Audit Trail** ознакомьтесь со списком всех транзакций синхронизации со статусами (`SUCCESS`), количеством записей и временем выполнения.

### Сценарий 5: Аудит и контроль соответствия (Compliance & Audit)
1. Авторизуйтесь как **Аудитор** (`auditor@techcorp.com` / `password`).
2. Откройте **Комплаенс (Compliance)** для отслеживания индикаторов рисков и сроков сдачи отчетности.
3. Перейдите в **Журнал аудита (Audit Logs)**: убедитесь, что каждое действие пользователей (вход, изменение данных, трансформация, экспорт) фиксируется с фиксацией IP, пользователя и временной метки.

## 5. Архитектура и безопасность

- **Backend:** FastAPI (Python 3.12), SQLAlchemy 2.0 ORM, Alembic миграции.
- **Frontend:** React 18, Vite, TypeScript, TailwindCSS, Lucide Icons, i18next (мультиязычность).
- **База данных:** SQLite (для локального PoC) / PostgreSQL 15 (для корпоративного развертывания).
- **Векторная база:** ChromaDB для семантического RAG-поиска по нормативным актам.
- **Безопасность:** JWT токены (HS256), хеширование паролей bcrypt, ролевая модель доступа (RBAC), изоляция данных по компаниям (Multi-tenancy).

## 6. Устранение неполадок (FAQ)

**В: При входе возникает ошибка CORS в браузере.**  
*О: Браузер мог закешировать предыдущий заголовок. Выполните жесткую перезагрузку страницы (`Ctrl+Shift+R` / `Cmd+Shift+R`) или откройте вкладку в режиме инкогнито.*

**В: Документы OCR выдают ошибку при загрузке сканов.**  
*О: Убедитесь, что в системе установлены утилиты `tesseract` и `poppler` (при запуске через Docker они уже включены в контейнер).*

**В: Как изменить ключ OpenAI для продакшн-тестирования?**  
*О: Укажите ваш ключ в файле `.env` в параметре `OPENAI_API_KEY="sk-..."` и перезапустите бэкенд.*
