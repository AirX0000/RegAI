# 🦅 RegAI (Axiaris) — Developer & Agent Guidelines

## 🎯 Mandatory Skill & Plugin Utilization Workflow

При выполнении любых задач в проекте RegAI (Axiaris) агент **обязан** системно использовать установленные плагины, скиллы и статьи из базы знаний:

### 1. Веб-интерфейс и стили (`modern-web-guidance` & `a11y-debugging`)
- Перед созданием или изменением UI-компонентов использовать `modern-web-guidance` для поиска современных веб-паттернов (HTML5 Dialog, CSS Grid, `color-scheme`, dark mode, micro-interactions).
- Соблюдать правила адаптивности Recharts согласно Knowledge Item `recharts_responsive_container_fix` (обязательное использование `min-w-0` и явной высоты `minHeight` для обёрток графиков).
- Обеспечивать поддержку доступности (ARIA-метки для интерактивных элементов, контрастность, управление фокусом).

### 2. Ревизия кода и качество (`coderabbit-reviewer`)
- Проводить сквозной статический аудит в стиле CodeRabbit перед завершением задачи:
  - Проверка безопасности (SQL injection, XSS, корректность шифрования Fernet).
  - Устранение N+1 запросов и неоптимальных циклов.
  - Строгая типизация (Pyright / TypeScript без `any` там, где возможна явная типизация).
  - Форматирование markdown и исключение линт-ошибок.

### 3. Бэкенд и безопасность (`fastapi_testing_debug_patterns`, `admin_audit_system`)
- Любые новые эндпоинты покрывать автоматическими тестами `pytest`.
- Конфигурация тестов должна опираться на `pytest.ini` (`pythonpath = .`).
- Чувствительные учетные данные (пароли 1C, токены API) обязательно шифровать через `app.core.crypto.encrypt_secret`.
- Действия пользователей протоколировать в `AuditLog` с сохранением IP-адреса и JSON-деталей изменений.

### 4. Непрерывная верификация
- Ни одна задача не считается завершенной без успешного прогона:
  1. `pytest` в `backend/` (все тесты должны быть зелеными).
  2. `npm run build` в `frontend/` (сборка TypeScript/Vite без ошибок типов).
